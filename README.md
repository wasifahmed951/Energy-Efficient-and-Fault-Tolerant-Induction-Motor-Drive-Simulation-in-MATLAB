# Energy-Efficient-and-Fault-Tolerant-Induction-Motor-Drive-Simulation-in-MATLAB
This repository contains the simulation benchmark, machine-learning code and results for a like-for-like comparison of indirect field-oriented control (IFOC) and direct torque control (DTC) on one saturated 4 kW, 400 V, 50 Hz induction motor, carried through to the traction drive of an automated guided vehicle (AGV).
